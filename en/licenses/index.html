Practical-RIFE interpolation model

The app bundles a converted Core ML version of Practical-RIFE 4.25-lite for optional on-device frame interpolation. The upstream project is hzwer/Practical-RIFE. The model weights were obtained from the Comfy-Org tensor-only mirror, using rife_v4.25_lite.safetensors. No ComfyUI application code is included.

The upstream project identifies the linked trained models as covered by its MIT license. The copyright and permission notice are reproduced below. The app’s FP16 conversion uses a 512 × 512 model canvas with aspect-preserving preprocessing; a larger movie export does not imply that the model inferred native detail at that resolution. It runs locally and does not require a model download when the app is used.
